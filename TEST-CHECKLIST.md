# Device testing checklist

- Install and launch; verify Now screen with sample data and images
- Complete onboarding and change display name
- Visit all sections: Now, Moments, Capture, Ask, Me, Timeline, etc.
- Switch Light/Dark theme
- Add/edit/complete/reopen a task
- Use Android Back to close dialogs
- Capture image from picker and camera
- Capture Food with linked expense
- Favorite/edit/delete a moment
- Export CSV, JSON, and SVG through Save As
- Add a reflection; check stories
- Add an event and mark prepared
- Check a habit; force-close and verify persistence
- Test offline (code and photos should work; fonts may fall back)
- Rotate device; test tablet if available
- Test reset only after exporting data you want to keep
